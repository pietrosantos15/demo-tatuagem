# Nanquim Tattoo Studio: site de demonstração (estúdio de tatuagem, Sorocaba/SP)

Landing page estática (HTML, CSS e JS puros, sem build). Marca, endereço, telefone e equipe são fictícios.

## Personalização por link
`index.html?wa=5515999998888&nome=Nome%20do%20Estudio` troca o WhatsApp de todos os botões, o telefone exibido e o nome da marca/título.

## Referência
Estrutura inspirada em landing pages de estúdios reais: Inkaholik (https://www.inkaholik.com: hero com chamada para agendar, estilos como categorias, prova de biossegurança, artistas) e Dr. Woo (https://www.drwoo.com: visual escuro, galeria como protagonista). Tattoo2me (blog brasileiro) foi lido só como apoio de vocabulário. Cores e fontes não puderam ser extraídas do CSS; a paleta foi definida por aproximação. Nada foi copiado (nome, logotipo, textos, imagens).

## Visual
- Paleta: tinta `#0F0F10`, grafite `#1A1A1D`, painel `#242428`, osso `#ECE5D8`, cinza quente `#A9A398`, vermelhão `#E4512F`, WhatsApp `#25D366`.
