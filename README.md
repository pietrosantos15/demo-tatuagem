# Nanquim Tattoo Studio (site de demonstração)

Site estático (index.html, style.css, script.js) para estúdio de tatuagem. Marca, endereço (Sorocaba, fictício) e telefone são fictícios.

Direção: editorial/galeria. Papel #F2EEE6, tinta #14110F, bege #E9E3D7 e acento vermelho nanquim #B8321E. Fontes: Instrument Serif (títulos) e Hanken Grotesk (texto).

Personalização por link: `?wa=5515999998888&nome=Nome%20do%20Estudio`.

Fotos que falham ao carregar são removidas e a grade se reorganiza sem buracos (onerror + script.js).
